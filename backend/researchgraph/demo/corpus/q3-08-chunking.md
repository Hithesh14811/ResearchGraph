# Chunk Size and Faithfulness Trade-offs in Retrieval-Augmented Generation

## Abstract

Increasing chunk size from 256 to 1,024 tokens improved faithfulness on long-form answers by 5 points but reduced precision on factoid questions by 4 points. No single chunk size was optimal across tasks.

## Recommendation

Tune chunk size per task type and evaluate retrieval precision and answer faithfulness together.
