# Has long context made RAG obsolete?

Original post: With million-token windows, long context made RAG obsolete for us because we just paste every document into the prompt.

Reply: Long context is always better than retrieval because the model sees everything at once.

Reply: Our costs went up a lot when we switched to long prompts, and each request became noticeably slower.

Reply: Retrieval still wins when the corpus is bigger than the context window.
